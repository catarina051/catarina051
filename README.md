## Featured projects

### [GradMent Data Platform](https://github.com/catarina051/gradment-data-platform)

An end-to-end Data and Analytics Engineering platform for a live EdTech product, published
with a safe synthetic-data lane. It covers event tracking, Airflow/dbt ELT, a PostgreSQL
star schema, Metabase dashboards, data contracts, quality tests, lineage, and CI/CD.

`Python` · `SQL` · `Apache Airflow` · `dbt` · `PostgreSQL` · `Metabase` · `Docker`

### [Skillcord](https://github.com/catarina051/skillcord)

A local-first AI development runtime prototype for reproducible coding-agent
configuration. It explores deterministic provider discovery, capability overlap
resolution, content locking, safe managed-file synchronization, and machine-readable
runtime health checks.

`Python` · `Pydantic` · `Jinja2` · `pytest` · `Ruff` · `mypy`

### [C++ Dungeon Crawler](https://github.com/catarina051/cpp-dungeon-crawler)

A finished top-down dungeon crawler built with C++17 and SFML. The project includes
continuous movement, collision handling, room progression, multiple enemy behaviors,
projectile systems, rewards, and a complete game-state flow.

`C++17` · `SFML` · `CMake` · `Game systems` · `Object-oriented design`
